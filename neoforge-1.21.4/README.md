# TpSetHome - NeoForge 1.21.4

Module NeoForge indépendant pour Minecraft 1.21.4. Les commandes disponibles sont `/sethome <nom>`, `/home <nom>` et `/delhome <nom>`.

Le code métier et le stockage sont partagés avec le module `common`. Le code d'intégration NeoForge et sa configuration de build restent dans ce dossier.
